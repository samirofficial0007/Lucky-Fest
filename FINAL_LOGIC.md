# Final Logic

- Every Telegram account has isolated MongoDB data.
- `/start` registers the user and handles valid referral attribution.
- Account page shows Assistant Bangladesh identity, level, total balance, invited-by, coin balance, USDT balance, referral income, referral coins, withdrawn USDT, language, theme, operations, FAQ, help and version.
- Gifts page: “Open gifts and get free coins”, +1 gift for every invite, Copy and Invite.
- How to earn: investment path and invite path.
- Direct invite rewards: +50/+30/+20/+10/+10 coins by registration position; +1 gift per successful invite.
- Five-level top-up commission: 10% / 3% / 2% / 1% / 1%.
- Live online count uses unique Telegram users with a heartbeat in the last 45 seconds; the UI refreshes every second.
- Top-up and withdrawals remain request-based until a real payment/custody provider is connected; no fake blockchain confirmations.
- Exact investment/agent rate tables that were not visible in the supplied screenshots are deliberately configurable rather than invented.
